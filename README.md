# HERMES Helfer

An assistant that guides projects through the HERMES project management method. AI agents draft deliverables, check quality and keep the project record. People release results and make every decision.

It runs on Microsoft Entra ID, SharePoint Online, Microsoft 365 and Azure (Microsoft Foundry).
